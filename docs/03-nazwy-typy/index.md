# 3. Nazwy i typy

Rozdział wprowadza dwa filary języka Python: system **nazw** (identyfikatorów), które są referencjami do obiektów, oraz katalog **typów prostych** wraz z mechanizmami ich sprawdzania i konwersji. Omawiamy również model pamięci — to on wyjaśnia, dlaczego przypisanie w Pythonie zachowuje się inaczej niż w wielu innych językach — oraz komplet operatorów.

Sterowanie przepływem programu (instrukcje warunkowe, pętle) opisuje rozdział [4. Sterowanie przepływem](../04-sterowanie/index.md), a typy złożone (listy, krotki, słowniki, zbiory) — rozdział [5. Typy złożone](../05-typy-zlozone/index.md).
